# X AI 回复助手

那位大佬能拯救一下，搞了半天回复的能力还是拉跨


在 [x.com](https://x.com) 的回复框旁加一个闪电按钮，根据帖子正文、引用帖、线程上下文、作者近期帖和评论，生成 **说人话的中文回复草稿**（默认 3 条，或「多角度」最多 5 条）。

Chrome / Edge 扩展 · Manifest V3 · 原生 JS 无构建 · MIT · v1.6.0

> 只生成草稿，不自动发帖。所有内容都需要你人工确认后手动发送。
>
> 「回复后给原帖点赞」为**可选**功能，**默认关闭**；开启后也只在你手动发送成功后尽力点赞，不会代发。X 改版可能导致点赞 DOM 失效。

## 为什么做这个

AI 写出来的评论一眼假：客套开场、排比三连、动不动总结升华。这个扩展不追求“更会写”，而是尽量写得像一个真人刷到帖子后随手打的一句话。

- **按帖型生成**：自动判断提问、发布、段子、个人经历、观点帖，不同帖型用不同策略
- **模式池**：从共鸣、补充、经验、具体认同、温和异议、接梗、追问、短反应里抽 3 种，不再固定“吹捧 / 反驳 / 答问”三件套
- **长短拉开**：一条 5~15 字、一条 15~35 字、一条 35~60 字，避免三条一个节奏
- **允许问句**：三条里最多一条真问句，不再机械地把问号替换成句号
- **多样性检查**：开头或句式太像、出现套路开场时，自动重写一次
- **上下文完整**：正文、引用帖、线程上文、作者近期帖、评论区精选一起进提示词
- **评论精选**：按作者回复、点赞、提问排序并去重；默认 15 条，可在设置里调 10–30；提示词禁止复读评论区
- **人设可编辑**：内置「默认友善」口吻，也可以改成你自己的说话方式
- **人设预设**：默认友善 / Serena / awe0 / Stanley / 自定义；面板一键切换，自定义文案单独保存
- **热键**：`Alt+Shift+G` 生成、`Alt+Shift+F` 填入第 1 条、`Alt+Shift+N` 下一条
- **失败可重试**：限流 / 超时等错误有中文说明和「重试」按钮（仍不代发）
- **多角度**：一键出最多 5 条不同角度（认同 / 补充 / 异议 / 玩笑 / 答问），点选填入回复框
- **今日待回**：在通知/提及页尽力收集待互动帖，弹窗与浮层可打开、标记已回或忽略（检测为 best-effort）
- **未回关**（只读）：在已登录的 x.com 里扫描「你关注了、对方没回关」的账号，可打开主页、导出 CSV。不自动取关、不自动关注、不发帖
- **草稿评价**：👍满意 / 👎不行（可写理由），本地保存；下次生成自动带「用户偏好」样例；硬过滤踩雷近重复，状态栏提示滤掉条数
- **当前帖高亮**：描边发光 + 面板「当前：@handle · 正文前20字」；自动生成时标记下一条将触发的帖
- **快速模式**（默认开）：更短提示、更少上下文、更低 max_tokens，状态栏显示耗时；「质量优先」可关捷径
- **楼中楼回评论**：评论旁「回这条」，或聚焦评论下的回复框 → 针对该评论生成草稿（原帖蓝高亮 + 评论绿高亮）；写完即赞仍只赞原帖
- **回复后给原帖点赞**（默认关）：发送成功后随机延迟 0.3–0.7 秒，尽力给原帖点赞（跳过已赞/自己的帖）

## 安装

目前从源码加载，无需构建。

1. 克隆或下载本仓库
   ```bash
   git clone https://github.com/<your-name>/x-ai-reply-helper.git
   ```
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
3. 打开右上角 **开发者模式**
4. 点 **加载已解压的扩展程序**，选择项目目录
5. 点扩展图标 → **打开设置**，填写 API Key、Endpoint、模型并保存
6. 打开任意 x.com 帖子页，在回复工具栏旁点闪电

> 如果之前已经加载过旧版本：在扩展卡片上点 **重新加载**，并关掉所有 x.com 标签页再重新打开。

## 配置

支持任何 OpenAI 兼容的 `chat/completions` 接口。

| 配置项 | 说明 |
| --- | --- |
| API Key | 服务商生成的 Key，只保存在浏览器扩展存储里 |
| Endpoint | 完整的 chat completions URL |
| 模型 | 可手动填写，也可点“读取模型”从接口拉取 |
| 回复人设 | 可编辑，决定语气和说话习惯 |
| 评论区抽样 | 10–30 条，默认 15；按作者回复/点赞/提问精选并去重 |
| 快速模式 | 默认开。短提示、少上下文、约 400/600 max_tokens；仅严重相似才重写 |
| 质量优先 | 默认关。开启后忽略快速捷径 |
| 回复后给原帖点赞 | 默认关。手动发送后尽力点赞原帖；不代发；依赖 X DOM |

OpenCode 示例：

| 项 | 值 |
| --- | --- |
| Endpoint（Go） | `https://opencode.ai/inference/go/openai/v1/chat/completions` |
| Endpoint（标准） | `https://opencode.ai/inference/openai/v1/chat/completions` |

模型建议使用表达力强一些的（Claude Sonnet、GPT-4.1、DeepSeek V3 等）。`gpt-4o-mini` 这类小模型更容易写成模板腔。

## 使用

1. 打开帖子页，或点回复打开输入框
2. **回原帖**：点工具栏旁的 **闪电**，或面板 **生成回复**（`Alt+Shift+G`）；需要更多选择时点 **多角度**
2b. **回某条评论（楼中楼）**：点该评论下方互动栏旁的 **回这条**，或先点 X 自带「回复」打开对该评论的输入框再生成——草稿会带上原帖与线程上下文
3. 每条草稿会标注生成模式（共鸣 / 补充 / 追问等；多角度为认同/补充/异议/玩笑/答问）
4. 点 **填入回复框** 或 **复制**，确认后自己点发送；也可用 **👍满意 / 👎不行** 教模型你的口味（可选理由）
5. 热键：`Alt+Shift+F` 填入第 1 条；`Alt+Shift+N` 切换下一条并填入
6. 面板顶部可切换人设预设（Serena / awe0 / Stanley / 自定义）
7. **今日待回**：先打开 [通知](https://x.com/notifications) 或提及页刷一下，再点面板「待回」或扩展弹窗查看；点「打开」进帖，回完点「已回」或忽略
8. **未回关**：扩展弹窗或设置页点「未回关」，或在自己的主页 / 正在关注页点左下角「未回关」。点「扫描未回关」，看进度（已扫关注 / 粉丝），点「打开主页」自己去看。可停止、导出、清空。上限默认 2000，在设置里改。结果存在本机，不进同步

可选项：

- **同帖缓存（约 5 分钟）**：同一帖子不重复请求；已有草稿时再点生成会强制刷新
- **打开回复框自动生成**：每个帖子只自动生成一次，不会循环
- **生成后自动填入第 1 条**：只填入，不会发送
- **快速模式 / 质量优先**：面板与设置页可切换；默认快速
- **回复后给原帖点赞**：默认关；开启后监听你点 X 的「回复/发帖」按钮，在 composer 清空等启发式判定发送成功后，对**原帖/根帖** `button[data-testid="like"]` 点击（已赞用 `unlike` / `aria-pressed` 判断并跳过；自己的帖用侧栏/个人页 handle 比对跳过）。**楼中楼场景也只赞原帖，不会给被回复的那条评论点赞。**

### 热键说明

| 快捷键 | 作用 |
| --- | --- |
| `Alt+Shift+G` | 生成 / 强制刷新草稿 |
| `Alt+Shift+F` | 填入第 1 条草稿 |
| `Alt+Shift+N` | 切换到下一条并填入 |

可在 `chrome://extensions/shortcuts` 修改。页面内也有同组合键兜底监听。

## 工作原理

```
content.js（x.com 页面）
  抓取正文 / 引用帖 / 线程 / 作者近帖 / 评论
        │
        ▼
background.js（Service Worker）
  识别帖型 → 抽 3 种回复模式 → 组装提示词
        │
        ▼
你配置的 OpenAI 兼容接口
        │
        ▼
解析 JSON → 相似度检查 → 必要时重写一次 → 渲染草稿
```

没有自建服务器，没有中转，也没有统计上报。

未回关不走上面的模型接口。它在 x.com 页面里用当前登录态读取关注/粉丝列表（只读 GET），在本地做差集。网页客户端那个公开 Bearer 不是你的密钥；真正的登录凭据仍是浏览器里的 cookie，扩展不会把它另存一份。

## 隐私

- API Key 存在 `chrome.storage.sync`，会随浏览器账号同步；共用电脑时请留意
- 只有在你点“生成”时，帖子内容和上下文才会发送到你自己配置的 Endpoint
- 草稿评价存在本机 `chrome.storage.local`（`replyFeedback`）；生成时仅把精简样例发给你配置的模型 Endpoint
- 不上传任何数据到第三方，不包含遥测
- 不要使用来源不明的中转接口，避免 Key 和内容被记录

## 已知限制

- X 的 DOM 结构变化可能导致抓取失败，需要跟随更新
- 目前只生成中文回复
- 需要桌面版 Chrome / Edge，不支持移动端
- 草稿质量取决于模型和人设，仍建议逐条人工检查
- 请遵守 X 与 API 服务商条款，不要用于刷评论
- **今日待回是尽力而为**：只根据当前页可见的通知/提及卡片收集，无法调用 X 私有 API 精确判断「你是否已回复」；可能漏检、重复或误收。填入草稿会按 statusId 标记已回，也可手动「已回 / 忽略」
- 未接入 Oh My X 类整站增强（垃圾过滤、爆款雷达等）；本扩展专注写草稿与待回整理
- **回复后点赞是尽力而为**：靠 DOM 找原帖 article + `data-testid="like"`；发送成功靠 composer 清空等启发式，可能漏赞或误判；X 改版需跟进
- **未回关是只读的**：优先看关注列表里有没有「回关 / Follows you」标记；没有标记时才对照粉丝列表。X 有时会拦住完整粉丝列表，这时扩展会说明原因，而不是把所有关注都当成未回关。扫描有上限，页与页之间会停顿。接口改版后可能要刷新 x.com 再扫
