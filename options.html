怎么用
  • 打开帖子页或点回复打开 compose 弹窗
  • 在回复工具栏旁点闪电，或面板「生成回复」；热键 Alt+Shift+G 生成、F 填入第1条、N 下一条
  • 面板可一键切换人设预设（Serena / awe0 / Stanley / 自定义）
  • 可选：自动生成 / 同帖缓存 / 自动填入 / 回复后点赞（默认关）/ 快速模式（默认开）/ 质量优先
  • 生成时会带上线程上文 + 本页同作者近帖（若 DOM 可见）
  • 复制或「填入回复框」后，再自己点发送（扩展不会代发）
  • 未回关：在已登录的 x.com 打开面板，点「扫描未回关」。只列出并打开主页，不会自动取关
  • 每条草稿可点 👍满意 / 👎不行（可写一句话理由）；下次生成会参考本地评价
  • 限流 / 超时时状态区会出现「重试」按钮
